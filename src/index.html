Code die je in één oogopslag leest

Hieronder krijg je vijf stukjes HTML en CSS die rommelig zijn ingesprongen. Jij zet de spaties goed. Klopt alles, dan ga je door naar de volgende opgave. Na de vijfde opgave wacht er een laatste vraag.

De regels

Alles wat binnen een ander element staat, schuift één stap naar rechts. De sluit-tag staat op die manier recht onder de open-tag.

In CSS schuiven de eigenschappen tussen { en } één stap naar rechts. De sluitende } staat recht onder de selector.

Eén stap is 2 spaties (4 mag ook, als je het maar overal hetzelfde doet). Je past alleen spaties aan, de code zelf blijft hetzelfde.

HTML

Tab schuift de regel 2 spaties naar rechts, Shift + Tab terug naar links. Werkt ook met meerdere regels geselecteerd. Druk eerst Esc om met Tab de editor te verlaten.

Zie je het verschil?

Links de code zoals je hem kreeg, rechts jouw versie. Volg de hulplijnen: rechts staat alles wat bij elkaar hoort recht onder elkaar.

Reflectie

Welke code zou jij liever tegenkomen?

Twee versies van hetzelfde profielkaartje. Ze doen in de browser precies hetzelfde. Kies de versie die jij beter vindt en leg uit waarom.

Schrijf minimaal 10 woorden.

Terug naar opgave 1

Je koos de rommelige versie. Kijk nog eens naar die code: kun je zien in welke <div> de <ul> staat? En welke </div> bij welke <div> hoort?

Bij de nette versie zie je dat meteen, zonder te tellen. Dat is precies waarom inspringen bestaat. Doe de opgaven nog een keer en let erop hoe snel je de structuur ziet als het klaar is.

Je snapt waarom het netjes moet. Nu mag je het ook snel.

Visual Studio Code kan een heel bestand in één keer netjes inspringen. Deze sneltoets heet Document opmaken (Format Document):

WindowsShift + Alt + F
macOSShift + Option + F
LinuxCtrl + Shift + I

Geen zin in sneltoetsen? Rechtermuisknop in je code en kies Document opmaken.

Wil je dat het vanzelf gebeurt? Zet in de instellingen Format On Save aan. Dan wordt je code elke keer netjes als je opslaat.

Het verschil tussen jou en iemand die alleen de sneltoets kent: jij ziet het meteen als de structuur niet klopt.
